# WAVets2Tech Portal

A full-stack **veteran-to-tech career platform** built for Saint Martin's University WAVets2Tech program, connecting military veterans with technology employers and career resources.

> **Role:** Team Lead & Front-End Developer
> **Year:** 2023
> **Team:** Cross-functional team of four
> **Stack:** React, ASP.NET Core Web API, C#, JavaScript, HTML/CSS

## Overview

The WAVets2Tech Portal was built in partnership with the Saint Martin's University Vets2Tech program to create a centralized hub for veterans transitioning into tech careers. The platform features job listings, veteran profiles, and an employer directory managed through a full RESTful API backend.

## Features

- **Job Listings** - searchable and filterable job board tailored for veteran candidates
- **Veteran Profiles** - portfolio-style profiles highlighting military experience and tech skills
- **Employer Directory** - company listings with contact info and open positions
- **Full CRUD** - complete create/read/update/delete operations across all entities
- **Client-Driven Development** - requirements gathered directly from program stakeholders

## How to Run

```bash
# Backend (ASP.NET Core API)
cd "WAVets2Tech API"
dotnet restore
dotnet run

# Frontend (React)
cd client
npm install
npm start
```
